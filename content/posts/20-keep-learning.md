There is just something that AI has done that has tremendously changed the direction of what it means to be a software
developer now. It just feels like there is no need to open up your editor, dive into the code, contextualize and then
solve the problem.

Nowadays, you just open up this "agentic" desktop or terminal app, type out what feature or issue you want to work on
and just sit back and let the AI do the work. The feeling is surreal, it's alien, it feels like a whole different world.

I don't like this feeling. It's like I'm offloading a part of my brain to some autonomous system that already knows my
next move without even getting to know me or how I work when it come to software development.

Also not to mention the cost of using AI, as I mentioned in a [previous post](/posts/18-the-ai-hype-is-dead#side-note),
this is the first time I've every actually spent money when it comes to my development workflow. I would like to lessen
this cost yet again while cheap I'd rather get the convenience for free 😅

I am still using my editor (neovim btw), I do consult the AI here and there but my main dev workflow is thru neovim. I
go through the code it modifies and if there is something that I don't like then I refactor it myself.

Note, I only use this for work, not something I would like to entertain for my hobby projects or my dotfiles, for now at
least. I am knowledgeable enough to work on those without relying on AI at all.

Another thing to mention are new technologies keep popping up. AI needs to be trained on new data to know how to use
them. New framework versions will release which will prompt more AI training.

If I keep learning and read the docs I will know about these before AI will and be able to utilise them in my projects
to keep them maintained. Sure AI will quickly adapt but I take the leisure that I will still be faster and knowledgeable
in this field.

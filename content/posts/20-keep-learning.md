There is just something that AI has done that has tremendously changed the direction of what it means to be a software
developer now. It just feels like there is no need to open up your editor, dive into the code, contextualize and then
solve the problem.

Nowadays, you just open up this "agentic" app on the desktop or terminal, type out what feature or issue you want to
work on and just sit back and let the AI do the work. The feeling is surreal, it's alien, it feels like a whole
different world.

I don't like this feeling. It's like I'm offloading a part of my brain to some autonomous system that already knows my
next move without even getting to know me or how I work when it come to software development.

As I mentioned in a [previous post](/posts/18-the-ai-hype-is-dead#side-note), this is a first time in a good while that
I've ever actually spent money when it comes to my development workflow. I would like to lessen this cost yet again,
while cheap I'd rather get the convenience for free 😅

I still use my neovim editor, I do get the AI to edit here and there but my main dev workflow is through neovim. I go
through the code it modifies and if there is something that I don't like then I refactor it myself. AI is still quite
behind when it comes to programming the way I do, that's because its the culmination trained on "experienced" developers
on the internet but they are not me so they will not code like I would.

The other point is that there are existing software and frameworks that are still releasing new versions with
improvements that the AI is not trained on and will use the old methods when writing code. The new version are always
the better way to do things and sure you can get AI to read the docs or the MCP server and get it to write in the newer
way but that does not mean you should not be reading those docs, you should also be actively keeping tabs on it.

It's back to learning for me. I've used too much of AI in my work I need to make sure I understand what's happening. If
I don't know what's going on do I really call myself a software engineer? Am I valued enough to be solving problems? I
can't let a machine do all the work (this is another form of technical debt to my eyes).

The only thing standing between that is learning, the knowledge and the wisdom to apply it as an engineer. Whether AI
will be there or not, I will make sure I will be there to see through it with my own experience because it's not
personalised for me.
